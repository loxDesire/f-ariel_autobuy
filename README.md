# Ариель Бот

Бот для быстрой покупки лимитированных товаров на f-ariel.ru сразу несколькими
аккаунтами + графический интерфейс для настройки и запуска (Windows/macOS/Linux).

## Возможности

- У каждого аккаунта свой список `product_ids` — можно покупать разные товары
  разными аккаунтами за один запуск
- Один аккаунт — `scout` (разведчик): опрашивает появление товара на высокой
  частоте, остальные добавляют товары и оформляют заказ параллельно, как
  только сработал сигнал
- Точное время дропа сверяется через NTP (без изменения системных часов,
  работает одинаково на всех ОС), с периодической пересверкой каждые 10 минут
  и обновлением сессий (повторный логин) за 3 минуты до дропа — можно
  запустить бота заранее и оставить работать
- GUI: редактор аккаунтов, запуск/остановка с живым логом, история запусков,
  поиск доступных товаров прямо с сайта, проверка/выбор/создание получателя
  и способа доставки

## Установка

```
python -m pip install -r requirements.txt
```

## Настройка

Скопируй `config.example.json` в `config.json` и заполни своими данными:

```
copy config.example.json config.json
```

- `time` — время дропа по МСК
- `accounts` — список аккаунтов: `email`, `password`, `proxy` (необязательно),
  `product_ids` (список id товаров для этого аккаунта), `scout` (`true` ровно
  у одного аккаунта)

`config.json` в `.gitignore` — там реальные пароли, в репозиторий не попадает.

## Запуск

GUI:
```
python run_gui.py
```

Бот напрямую из консоли (без GUI):
```
python run_fast.py
```

## Готовые сборки

Есть скомпилированные версии под каждую ОС (не нужен установленный Python):
Windows `.exe`, macOS `.app`, Linux `.deb`.

При первом запуске рядом с приложением (для Linux — в `~/.config/arielbot/`)
создастся `config.json` — заполни его через саму вкладку «Аккаунты» в GUI или
вручную по образцу `config.example.json`.

### Как собрать самому

PyInstaller не кросс-компилирует — каждую сборку нужно собирать на своей ОС.

**Windows:**
```
powershell -ExecutionPolicy Bypass -File packaging\build_windows.ps1
```
Результат: `dist\ArielBot.exe`

**macOS** (на самой macOS):
```
bash packaging/build_macos.sh
```
Результат: `dist/ArielBot.app`

**Linux** (на самом Linux, нужен `dpkg-deb`):
```
bash packaging/build_linux_deb.sh
```
Результат: `dist/arielbot_1.0.0_amd64.deb`, ставится через
`sudo dpkg -i dist/arielbot_1.0.0_amd64.deb`

## Структура проекта

```
run_fast.py       — сам бот (логин, опрос, добавление в корзину, checkout)
run_gui.py         — точка входа: без флагов — GUI, с --run-bot — сам бот
                      (используется как отдельный процесс из вкладки «Запуск»
                      и в собранных .exe/.app/.deb, где нет отдельного python.exe)
config.json         — конфиг с реальными данными (не в git)
config.example.json — шаблон конфига
packaging/           — скрипты сборки .exe/.app/.deb, иконки
gui/
  app.py             — главное окно, вкладки
  accounts_tab.py     — редактор аккаунтов/конфига
  run_tab.py           — запуск/остановка бота, живой лог
  history_tab.py        — история запусков
  product_finder.py      — парсинг доступных товаров с сайта
  product_picker.py       — диалог выбора товаров
  recipient_finder.py      — проверка/выбор/создание получателя и доставки
  recipient_dialog.py       — диалог для recipient_finder
  theme.py                   — палитра и QSS-стиль
  widgets.py                  — переиспользуемые виджеты (теги, radio, иконки)
  assets/app_icon.svg          — иконка приложения
```
