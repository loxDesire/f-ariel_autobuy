# ARIELBOT

Бот для быстрой покупки лимитированных товаров на f-ariel.ru сразу несколькими
аккаунтами + терминальный интерфейс (TUI) — работает и локально, и на сервере
по ssh.

## Возможности

- У каждого аккаунта свой список `product_ids` — разные товары разными
  аккаунтами за один запуск
- Опрос появления товара — всеми аккаунтами параллельно, 3 воркера на аккаунт,
  до победного: сайт падает — запросы всё равно идут, пока товар не добавится
  и не оформится заказ
- Два режима: **ко времени** (точное время дропа по NTP) и **сразу**
- Подробный лог каждого запроса: отправлен / ответ / время ответа / что
  ответил сайт
- Уведомления в Telegram: запуск, товар в корзине, заказ оформлен/отклонён
  (если Telegram заблокирован — через свой Cloudflare Worker)
- TUI: запуск и остановка бота, полный лог + панель успешных, таймер до
  дропа, аккаунты, получатель и доставка (самовывоз / СДЭК), товары с сайта,
  история запусков, настройки

## Установка

```
bash setup.sh
```

Создаст `venv/` и поставит зависимости из `requirements.txt` (`venv/` в git
не попадает). Если `config.json` и `.env` ещё нет — скопирует их из
`config.example.json` и `.env.example`.

## Запуск

Интерфейс:
```
venv/bin/python run_tui.py
```

Бот без интерфейса (`now` — сразу, `time` — ко времени; без аргумента
спросит):
```
venv/bin/python run_fast.py now
```

На сервере запускай внутри `tmux`, чтобы всё продолжало работать после
отключения ssh:
```
tmux new -s bot
venv/bin/python run_tui.py
# отсоединиться: Ctrl+B, затем D;  вернуться: tmux attach -t bot
```

### Клавиши TUI

| Клавиша | Действие |
|---|---|
| `1`–`6` | Запуск · Аккаунты · Товары · История · Настройки · О программе |
| `s` / `x` | старт / стоп бота |
| `a` `e` `d` `o` | аккаунты: добавить, изменить, удалить, получатель и доставка |
| `l` | загрузить товары с сайта |
| `r` | обновить (история, получатель) |
| `esc` | из поля ввода обратно в меню |
| `ctrl+p` | палитра команд |
| `q` | выход |

## Настройка

Всё настраивается в TUI (вкладки «Аккаунты» и «Настройки») или вручную в
`config.json` по образцу `config.example.json`:

- `time` — время дропа по МСК
- `mode` — режим по умолчанию: `scheduled` (ко времени) или `now` (сразу)
- `accounts` — `email`, `password`, `proxy` (необязательно), `product_ids`
- `telegram` — уведомления вкл/выкл и имя программы (см. ниже)

Секреты Telegram — токен бота, chat id и адрес Cloudflare Worker — лежат
отдельно в `.env` (шаблон — `.env.example`): `TG_BOT_TOKEN`, `TG_CHAT_ID`,
`TG_API_BASE`.

`config.json` и `.env` в `.gitignore` — там пароли и токены, в репозиторий не
попадают.

## Уведомления в Telegram

Бот пишет в Telegram: запуск, товар в корзине, заказ оформлен (со ссылкой) /
отклонён, падение. Удобно слать в **общую группу** — туда могут писать сразу
несколько запущенных программ (каждая подписывается своим именем, например
`[сервер-1] ✅ Заказ оформлен!`). Один бот, один токен на все программы —
отправка сообщений из нескольких мест одновременно Telegram не мешает.

1. Создай бота у [@BotFather](https://t.me/BotFather) (`/newbot`) — получишь токен.
2. Если `api.telegram.org` заблокирован (в РФ — обычно да, и на сервере тоже) —
   подними прокси на Cloudflare Worker (бесплатно):
   - dash.cloudflare.com → Workers & Pages → Create → Create Worker → Deploy
   - Edit code → вставь `tools/tg-proxy-worker.js` → Deploy
   - URL воркера (`https://<имя>.<аккаунт>.workers.dev`) — это `api_base`
3. Добавь бота в группу и напиши там любое сообщение.
4. В TUI: Настройки → токен, API base → **«Найти группу»** → выбери группу →
   впиши «Имя программы» → включи уведомления → «Сохранить» →
   «Отправить тест».

Если группа станет супергруппой (Telegram меняет ей id) — бот сам отправит
по новому id и напишет в лог, на какой id обновить настройки.

## Структура проекта

```
run_fast.py          — сам бот (логин, опрос, корзина, checkout, уведомления)
run_tui.py           — точка входа TUI
tui/
  app.py             — главное окно: шапка, меню, экраны
  screens/run.py      — запуск/стоп бота, таймер, полный лог и успешные
  screens/accounts.py — аккаунты, получатель и доставка
  screens/products.py — товары с сайта -> аккаунтам
  screens/history.py  — история запусков
  screens/settings.py — время дропа, режим, Telegram
  config_store.py     — чтение/запись config.json
  styles.tcss         — оформление
core/
  recipient_finder.py — получатель и способ доставки через API сайта
  product_finder.py   — список доступных товаров с сайта
tools/
  tg-proxy-worker.js  — Cloudflare Worker для Telegram
check_session.py     — проверка: переживает ли сессия падение сайта
setup.sh             — создать venv и поставить зависимости
```
